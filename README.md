# Junior IT Internship 

Dokumentasi pengalaman Praktik Kerja Lapangan (PKL) selama 5 bulan di PT LintasMaya MultiMedia dengan fokus pada bidang IT Support, Network Installation, Wireless Infrastructure, dan Fiber Optic Networking.

Repository ini berisi dokumentasi pengalaman praktik, kegiatan teknis, penggunaan peralatan jaringan, serta keterampilan yang dikembangkan selama menjalani kegiatan magang.

## Technical Responsibilities

### 1. UTP Cable Installation
- Melakukan persiapan dan crimping kabel UTP menggunakan konektor RJ45.
- Menerapkan standar urutan warna T568B untuk kabel straight-through.
- Melakukan pengujian konektivitas kabel menggunakan LAN Tester.
- Membantu proses instalasi jaringan kabel.

### 2. Wireless Radio Installation
- Membantu proses perakitan perangkat radio RocketDish 30/34.
- Mempersiapkan antena, komponen mounting, dan kabel jaringan.
- Membantu instalasi perangkat wireless radio.
- Menghubungkan perangkat radio menggunakan kabel UTP dan PoE adapter.
- Membantu teknisi dalam proses radio alignment dan pemeriksaan konektivitas.

### 3. Fiber Optic Splicing
- Melakukan persiapan dan pengupasan kabel fiber optic.
- Membersihkan fiber core sebelum proses penyambungan.
- Menggunakan fiber cleaver untuk mempersiapkan ujung fiber.
- Membantu proses fusion splicing menggunakan fiber optic splicer.
- Mempelajari proses pengujian fiber optic menggunakan OPM dan OTDR.

### 4. IT Support & Technical Assistance
- Membantu persiapan dan konfigurasi perangkat jaringan di bawah pengawasan teknisi.
- Membantu pemeriksaan dan persiapan perangkat jaringan.
- Membantu proses penonaktifan user account sesuai instruksi.
- Mendukung persiapan peralatan dan kegiatan administrasi.
- Membantu teknisi selama kegiatan instalasi di lapangan.
