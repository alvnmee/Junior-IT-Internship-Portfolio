# Junior IT Internship 

A portfolio documenting my 5-month internship experience at PT LintasMaya MultiMedia, focusing on IT Support, Network Installation, Wireless Infrastructure, and Fiber Optic Networking.

This repository showcases my practical experience in assisting network technicians, supporting IT infrastructure installations, and performing network-related technical tasks.

| Category | Details |

| Company | PT LintasMaya MultiMedia |

| Period | November – March |
| Location | Samarinda, Indonesia |
| Industry | IT Services |

## Technical Responsibilities

### 1. UTP Cable Installation
- Prepared and crimped UTP cables using RJ45 connectors.
- Applied the T568B color sequence for straight-through cables.
- Tested cable connectivity using a LAN Tester.
- Assisted with wired network installation activities.

### 2. Wireless Radio Installation
- Assisted in assembling RocketDish 30/34 radio equipment.
- Prepared antennas, mounting components, and network cables.
- Assisted with wireless radio installation.
- Helped connect radio equipment using UTP cables and PoE adapters.
- Assisted technicians with radio alignment and connection checks.

### 3. Fiber Optic Splicing
- Prepared and stripped fiber optic cables.
- Cleaned fiber cores before splicing.
- Used a fiber cleaver to prepare fiber ends.
- Assisted with fusion splicing using a fiber optic splicer.
- Learned fiber optic testing using OPM and OTDR equipment.

### 4. IT Support & Technical Assistance
- Assisted with network device preparation and configuration under technician supervision.
- Helped inspect and prepare networking equipment.
- Assisted with user account deactivation as instructed.
- Supported equipment preparation and administrative activities.
- Assisted technicians during field installation activities.
